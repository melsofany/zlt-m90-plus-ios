# ZLT M90 Plus iOS

تطبيق iOS مبدئي لإدارة جهاز **ZLT M90 Plus** من خلال شبكة Wi‑Fi المحلية. الواجهة مبنية بـ SwiftUI وتحتوي على شاشة اتصال، لوحة حالة، وإعدادات Wi‑Fi.

## الحالة الحالية

هذه نسخة scaffold قابلة للتطوير. تختلف مسارات API وصيغة تسجيل الدخول بين إصدارات Firmware ومزوّدي الخدمة، لذلك وضعت طبقة `RouterAPI` في مكان واحد. وظائف الواجهة تعمل مبدئيًا ببيانات تجريبية إلى أن يتم التقاط طلبات واجهة الويب من جهاز فعلي.

## التشغيل

افتح المشروع في Xcode 15 أو أحدث على macOS، ثم أنشئ iOS App target باسم `ZLTM90Plus` وانسخ ملفات `Sources/ZLTM90Plus` إلى target. الحد الأدنى iOS 16.

> لا يمكن بناء تطبيق iOS أصلي على Linux؛ يلزم macOS/Xcode للتوقيع والتشغيل على iPhone.

## اختبار الجهاز وربط API

1. اتصل بالـ Wi‑Fi الخاص بالجهاز.
2. افتح لوحة الإدارة في Safari عبر `http://192.168.0.1` أو العنوان الموجود على ملصق الجهاز.
3. افحص مسارات الطلبات وصيغة الاستجابة باستخدام أدوات تطوير Safari على Mac.
4. حدّث دوال `login`, `status`, و`updateWiFi` داخل `RouterAPI.swift`، مع عدم تسجيل كلمة المرور أو رموز الجلسة.
5. أضف `NSLocalNetworkUsageDescription` إلى إعدادات التطبيق قبل اختبار الوصول المحلي.

## الأمان

لا تُضمّن بيانات الدخول داخل المستودع. استخدم Keychain لحفظ رمز الجلسة بعد تحديد آلية المصادقة الفعلية للجهاز. التطبيق لا ينفذ أي تعديل فعلي على الراوتر في هذه النسخة حتى يتم تأكيد مسارات Firmware.

## الخطة التالية

- دعم تسجيل الدخول الحقيقي وCookie/CSRF إن وجد.
- قراءة حالة LTE، مستوى الإشارة، والاستهلاك.
- عرض الأجهزة المتصلة وحظرها.
- تعديل Wi‑Fi وإعادة التشغيل مع تأكيد داخل التطبيق.
- اختبارات API باستخدام استجابات محفوظة من جهاز حقيقي.
